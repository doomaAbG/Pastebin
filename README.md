# Pastebin на C++

Небольшой учебный Pastebin: веб-приложение, в котором можно сохранить текст и открыть его по короткой ссылке.

Сервер написан на C++ с использованием [Crow](https://crowcpp.org/) и сохраняет пасты в PostgreSQL через [libpqxx](https://github.com/jtv/libpqxx).

## Возможности

- Главная страница с формой для нового текста
- Сохранение пасты в PostgreSQL
- Просмотр сохранённой пасты по адресу вида `/paste/<id>`
- Создание таблицы `pastes` при запуске, если её ещё нет

## Как это устроено

1. При запуске приложение подключается к PostgreSQL и создаёт таблицу `pastes`.
2. Страница `GET /` показывает форму.
3. Форма отправляет текст запросом `POST /paste`.
4. Сервер создаёт ID и сохраняет текст с датой в базу.
5. Открытие `GET /paste/<id>` загружает текст по ID.

## Технологии

- C++20
- [Crow](https://crowcpp.org/) — HTTP-сервер и маршрутизация
- [PostgreSQL](https://www.postgresql.org/) — хранение паст
- [libpqxx](https://github.com/jtv/libpqxx) — C++ клиент PostgreSQL
- [CMake](https://cmake.org/) — конфигурация сборки

## Требования

- Windows и Visual Studio C++ Build Tools
- CMake 3.20 или новее
- PostgreSQL
- Библиотеки Crow, Asio и libpqxx

> Текущий `CMakeLists.txt` содержит локальные пути к Crow, Asio и libpqxx. Перед сборкой на другом компьютере эти пути нужно настроить под свою систему.

## Запуск

1. Установите PostgreSQL и запустите сервер базы данных.
2. Создайте базу данных с именем `pastebin_db`.
3. Проверьте строку подключения к базе в `src/main.cpp`. В текущей версии имя пользователя, пароль, хост и порт заданы прямо в исходном коде; для реального использования их следует вынести в переменные окружения.
4. Укажите корректные пути к Crow, Asio и libpqxx в `CMakeLists.txt`.
5. Из корня проекта выполните:

   ```powershell
   cmake -S . -B build
   cmake --build build --config Release
   .\build\Release\pastebin.exe
   ```

6. Откройте в браузере [http://localhost:8080](http://localhost:8080).

## Текущее состояние и известные ограничения

- Текущая версия кода использует PostgreSQL; папка `data/` относится к ранней файловой версии.
- Сервер слушает порт `8080`.
- Настройки зависимостей в CMake привязаны к конкретным путям на компьютере автора.
- Обработчик формы пока не полностью декодирует URL-кодированный текст.
- Текст пасты выводится в HTML без экранирования. Не размещайте приложение в открытом интернете без исправления этой проблемы и настройки безопасной конфигурации.
